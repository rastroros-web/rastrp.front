# Rastro Landing

Landing de **Rastro** (Next.js + Tailwind) inspirada en el estilo de [Laula Sport](https://www.laula.ar/), con logos, banners y productos sacados de la tienda original.

## Arrancar

```bash
cd ~/Desktop/PROYECTOS/rastro-landing
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Assets

- `public/assets/logo/` — logo y sello footer
- `public/assets/banners/` — slides / promos
- `public/assets/products/` — fotos de productos
- `src/data/` — JSON de productos y banners
